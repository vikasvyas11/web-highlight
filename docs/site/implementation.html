UNDERLIGHT / DOCUMENTATION

Implementation and releases

Underlight uses one Manifest V3 extension for all three browsers. Updated 16 November 2026.

From a selection to a record

The content script captures a DOM range in the main HTML document. A text-node index converts its endpoints into an exact quote, a starting offset, and nearby text. The selected action supplies the type and color. Notes add a plain-text comment. The new record is written to chrome.storage.local under a key containing its page URL and a unique ID.

Paint a saved passage

When a page opens, the script reads its records and resolves each quote against the current text. Prefix and suffix matches help distinguish duplicate quotes. The original offset is preferred when both sides still match. Unresolved records stay in storage. CSS Custom Highlights paint ranges without replacing the site's text nodes. A mutation observer schedules another pass when content changes.

The note editor uses a closed shadow root to isolate its controls from page styles. The library is a separate extension page. Storage change events refresh open library and page views. Each annotation has its own key, so adding one passage does not rewrite the other records on the page.

Work on the project

  1. Load extension/ unpacked in a browser and pin Underlight for easy access.
  2. Change the relevant JavaScript, CSS or HTML source.
  3. Reload the extension in the extension manager.
  4. Refresh the target page.

For automated checks, use Node.js 22.12 or newer with Git on the path.

npm ci
npx playwright install chromium
npm test
npm run docs:test

Pass an installed browser executable to npm test -- to run the same suite in that browser. Tests use a temporary profile that is removed afterwards. The README includes Windows examples for all three browsers.

Release 1.0.0 — 16 November 2026

The first release includes the selection toolbar, right-click actions, seven colors, quotation-based restoration, on-page note editing, and a searchable offline library. The project uses the MIT License. The documentation font has its own SIL Open Font License.

Status and evidence — 16 November 2026

Browser integration tests passed in desktop Chrome, Edge, and Brave on Windows, each based on Chromium 157. The tests saved 21 combinations, edited a note, restarted the browser, changed the document structure, navigated between page addresses, and deleted an annotation. Each browser kept the expected local records.

Support covers the main document on HTTP and HTTPS webpages. Private browser pages, PDF viewers, frames, and shadow-root content fall outside the tested annotation surface.
