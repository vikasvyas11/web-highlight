Using Underlight

Underline a sentence, highlight a passage, or leave a comment on the page where you found it. Updated 16 November 2026.

Install in your browser

  1. Clone or download the Underlight repository into a permanent folder.
  2. Open chrome://extensions, edge://extensions, or brave://extensions.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the repository's extension folder.
  5. Refresh the webpage you want to annotate.

Try your first note

  1. Select a passage on a regular webpage.
  2. Choose a color in the floating toolbar.
  3. Choose Note.
  4. Write a comment and click Save.

Click the dotted passage to open its note. Change the note or its color and choose Save. Use Delete to remove it. You can reopen the page later and click the same passage again.

Find a saved passage

Click the Underlight extension icon. The library shows each page title above its saved passages. Search for words in the passage, your comment, the page title, or its URL. Type tabs and the color filter work together. Click the page title to return to the source.

Use your annotations outside Underlight

Find the browser storage folder

Expand Saved in this browser profile in the library header. Open your browser’s version page and find Profile Path. Within that directory, the library shows the Local Extension Settings subfolder and Underlight’s extension ID. This location contains the browser-managed database.

Export for a research agent

  1. Filter the library to the material you want to share. Clear the filters for a complete export.
  2. Choose Export JSON to download the displayed results.
  3. Attach the JSON file to an agent or place it in the agent’s workspace.

The file groups passages by page title and URL. Each record separates the quoted source text from your note and includes its type, color, ID, and creation time. An agent can cite the links or consult the original paper for additional context.

Restore a missing mark

  • Refresh an already-open page after installing or updating the extension.
  • Check that Underlight has access to the site and you are using the same browser profile, page address, and unpacked extension folder.
  • Expand the article or scroll to load its text. The extension checks again as the page renders.
  • Open the library if the original wording changed. The saved quote and note are available there.
Keep your extension installed while updating. Removing it clears its local storage. The library is separate in each browser profile.
